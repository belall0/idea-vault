# Admin User Stories

## User Management

- [ ] As an admin, I want to view any user's profile and account details so that I can investigate reported or flagged behavior.
- [ ] As an admin, I want to permanently ban a user so that repeat or severe violators are removed from the platform.
- [ ] As an admin, I want the banned user to be notified with a reason so that they understand why they lost access.
- [ ] As an admin, I want all user management actions to be logged with a timestamp so that there is a clear audit trail for accountability.

## Content Oversight

- [ ] As an admin, I want to view the full moderation action log so that I can monitor moderator activity and catch errors or abuse.
- [ ] As an admin, I want to restore content that a moderator removed so that I can correct wrongful takedowns.
- [ ] As an admin, I want the content creator to be notified when their content is restored so that they are aware their content is back up.

## Role Management

- [ ] As an admin, I want to view all users and their assigned roles so that I can have visibility into who has elevated access on the platform.
