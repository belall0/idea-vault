# Moderator User Stories

## User Management

- [ ] As a moderator, I want to temporarily suspend a user so that I can restrict access for a set period without permanently banning them.
- [ ] As a moderator, I want the suspended user to be notified with a reason and duration so that they understand the restriction.

## Reports Queue

- [ ] As a moderator, I want to view a queue of all pending reports so that I can systematically review flagged content.
- [ ] As a moderator, I want to see the reporter's identity and reason when reviewing a report so that I can assess the validity of the claim.
- [ ] As a moderator, I want to dismiss a report so that I can clear false or frivolous flags from the queue.
- [ ] As a moderator, I want to mark a report as resolved after taking action so that the queue stays accurate and auditable.

## Content Actions

- [ ] As a moderator, I want to remove a reported idea so that violating content is taken down promptly.
- [ ] As a moderator, I want to remove a reported comment so that inappropriate feedback is taken down promptly.
- [ ] As a moderator, I want to proactively remove any idea or comment without a report so that I can act on content I notice directly without waiting for a member to flag it.

## Feedback & Audit

- [ ] As a moderator, I want the content creator to be notified when their content is removed so that they understand why it was taken down.
- [ ] As a moderator, I want all my moderation actions to be logged with a timestamp so that there is a clear audit trail for accountability.
