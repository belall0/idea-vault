# Member User Stories

## Auth

- [ ] As a member, I want to be able to create an account so that I can access personalized features.
- [ ] As a member, I want to be able to log in so that I can securely access my account.
- [ ] As a member, I want to be able to log out from my account so that I can protect my information when I'm done using the app.
- [ ] As a member, I want to be able to log out from all devices so that I can ensure my account is secure if I suspect unauthorized access.
- [ ] As a member, I want to be able to reset my password so that I can regain access to my account if I forget it.
- [ ] As a member, I want to be able to verify my email address so that I can ensure the security of my account and receive important notifications.
- [ ] As a member, I want to be able to delete my account so that I can remove my information from the platform if I choose to do so.

## Ideas

### Discovery

- [ ] As a member, I want to be able to view a paginated list of all ideas so that I can explore different startup concepts.
- [ ] As a member, I want to be able to search for ideas by keywords so that I can find specific concepts that interest me.
- [ ] As a member, I want to be able to filter ideas by categories so that I can easily find concepts related to specific industries or themes.
- [ ] As a member, I want to be able to sort ideas by popularity or recency so that I can discover trending concepts or the latest submissions.

### Management

- [ ] As a member, I want to be able to manage idea state (draft / published / private) so that I can control when and who sees my idea.
- [ ] As a member, I want to be able to create new ideas so that I can share startup concepts with others.
- [ ] As a member, I want to be able to assign categories or tags to my idea so that others can discover it through filtering.
- [ ] As a member, I want to be able to edit my ideas so that I can update them as they evolve.
- [ ] As a member, I want to be able to delete my ideas so that I can remove outdated or irrelevant concepts from my profile.

### Engagement

- [ ] As a member, I want to be able to view details of an idea so that I can learn more about it and potentially contribute to it.
- [ ] As a member, I want to be able to upvote ideas so that I can show my support for concepts I find interesting or promising.
- [ ] As a member, I want to be able to downvote ideas so that I can provide feedback on concepts I find less appealing or relevant.
- [ ] As a member, I want to be able to see the total number of upvotes and downvotes for each idea so that I can gauge its popularity and reception within the community.
- [ ] As a member, I want to be able to save my favorite ideas so that I can easily access them later.
- [ ] As a member, I want to be able to unsave ideas from my favorites so that I can manage my collection of interesting concepts.
- [ ] As a member, I want to be able to share ideas on social media so that I can spread the word about concepts I find interesting and engage a wider audience.
- [ ] As a member, I want to be able to report inappropriate ideas so that I can help maintain a positive and respectful community environment.

## Profile

- [ ] As a member, I want to be able to view my own profile so that I can see all my personal information and the ideas I've created.
- [ ] As a member, I want to be able to edit my profile bio, avatar, and links so that I can express my identity and help others learn more about me.
- [ ] As a member, I want to be able to view my saved ideas in my profile so that I can easily access the concepts I've marked as favorites.
- [ ] As a member, I want to be able to view other users' profiles so that I can learn more about them and their ideas.
- [ ] As a member, I want to be able to go to any idea's creator profile so that I can learn more about them and their other ideas.

## Comments

- [ ] As a member, I want to be able to view comments on an idea so that I can see what others think about it and join the discussion.
- [ ] As a member, I want to be able to see the number of comments on an idea so that I can gauge the level of discussion and engagement it has generated.
- [ ] As a member, I want to be able to comment on ideas so that I can provide feedback and engage with the community.
- [ ] As a member, I want to be able to reply to comments in threaded/nested discussions so that I can have more organized and meaningful conversations about ideas.
- [ ] As a member, I want to be able to edit my comments so that I can update my feedback or correct any mistakes.
- [ ] As a member, I want to be able to see comment change history so that I can track the evolution of the discussion and understand the context of edits.
- [ ] As a member, I want to be able to delete my comments so that I can remove any feedback that is no longer relevant or appropriate.
- [ ] As a member, I want to be able to report inappropriate comments so that I can help maintain a positive and respectful community environment.

## Notifications

- [ ] As a member, I want to receive notifications for new comments on my ideas so that I can stay engaged with the feedback and discussions around my concepts.
- [ ] As a member, I want to receive notifications for replies to my comments so that I can continue participating in conversations and respond to feedback.
- [ ] As a member, I want to receive notifications for upvotes on my ideas so that I can see which concepts are resonating with the community.
