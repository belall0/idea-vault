# Super-Admin User Stories

## Role Management

- [ ] As a super-admin, I want to assign the moderator role to any member so that I can grant content moderation privileges.
- [ ] As a super-admin, I want to revoke the moderator role from any user so that I can remove moderation privileges when no longer appropriate.
- [ ] As a super-admin, I want to assign the admin role to any member so that I can grant user management privileges.
- [ ] As a super-admin, I want to revoke the admin role from any user so that I can remove admin privileges when no longer appropriate.
- [ ] As a super-admin, I want to view all users and their assigned roles so that I can maintain full visibility into who has elevated access.

## Override Authority

- [ ] As a super-admin, I want to restore content removed by a moderator or admin so that I can correct any wrongful takedowns at any level.
- [ ] As a super-admin, I want to unban a user banned by an admin so that I can reverse unjust or erroneous permanent bans.
- [ ] As a super-admin, I want to unsuspend a user suspended by a moderator so that I can reverse unjust or erroneous temporary suspensions.
